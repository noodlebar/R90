[h1] R90
[h2] Product Intent / 产品意图
[p] ：R90 是一个可移植的 Agent Skill 和确定性 CLI 工具，用 90 分钟睡眠周期帮助用户围绕目标起床时间规划睡眠窗口，也支持“我要睡了”时反推适合的起床时间，并记录一周完成了多少个 R90 周期。
[strong] English
[p] : R90 is a portable Agent Skill and deterministic CLI utility for planning sleep around 90-minute recovery cycles. It calculates bedtime windows from a target wake time, suggests wake times from a lights-out time, and records lightweight weekly R90 cycle logs.
[strong] 安全边界 / Safety Boundary
[p] ：R90 只提供睡眠计划和自我记录参考，不是医疗建议；它不诊断睡眠问题、不治疗疾病，也不保证睡眠质量。R90 is planning guidance, not medical advice.
[h2] R90 Method Assumptions / R90 方法假设
[li] ：一个 R90 周期按 90 分钟计算。
[strong] English
[li] : One R90 cycle is treated as a 90-minute block.
[li] ：起床时间是锚点；睡觉窗口从目标起床时间倒推。
[strong] English
[li] : Wake time is the anchor; bedtime windows are calculated backwards from it.
[li] ：默认展示 4、5、6 个周期，方便用户在睡眠时长和现实安排之间选择。
[strong] English
[li] : The default options are 4, 5, and 6 cycles so users can compare practical choices.
[code] wind-down
[li] 是睡前准备时间，不计入实际睡眠时长。
[strong] English
[li] : Wind-down is preparation time and is not counted as sleep duration.
[li] ：一周追踪用用户自报记录统计，不代表设备验证过的真实睡眠。
[strong] English
[li] : Weekly tracking uses self-reported logs, not verified sleep measurements.
[li] ：遇到严重失眠、疑似睡眠呼吸暂停、长期疲劳等情况，应寻求专业帮助。
[strong] English
[li] : Severe insomnia, suspected sleep apnea, or long-term fatigue should be handled with professional help.

[h1] English Guide
[h2] Current Deliverable
[p] R90 currently ships as a portable Agent Skill and deterministic CLI utility:
[code] r90_sleep_planner
[li] : skill instructions, response rules, and safety boundaries.
[code] r90_calc.py
[li] : deterministic calculator used for all arithmetic.
[li] Local JSON logging for self-reported sleep-cycle check-ins.
[li] Platform adapter notes for OpenClaw, Codex, and MiClaw.
[li] Dual-track calculation: prefer the script or a host action; fall back to the manual algorithm embedded in
[code] SKILL.md
[li] when scripts are unavailable.
[li] Built-in validation through
[code] self-test
[p] There is no standalone web or mobile app yet. The usable surfaces are the Agent Skill and the bundled CLI script.
[h2] Features
[li] Bedtime windows from a wake target, showing 4, 5, and 6 cycles by default.
[li] Wake suggestions from a provided lights-out time or from "I am going to sleep now".
[li] Optional wind-down buffer, defaulting to 30 minutes, kept separate from sleep duration.
[li] Previous-day and next-day rollover notes.
[li] IANA timezone support through Python
[code] zoneinfo
[li] Low-friction check-in parsing, such as
[code] 23:30-07:00
[code] slept 7.5h
[li] , or
[code] skip
[li] Idempotent local sleep-log updates by date.
[li] Weekly R90 summary with target cycles, minimum useful range, and per-day rows.
[li] Conservative, non-clinical health language.

[li] ability to read
[code] SKILL.md
[li] , or register it as host instructions.
[li] ability to execute
[code] python3 scripts/r90_calc.py
[li] , or expose equivalent host actions.
[li] optional local/private storage for
[code] ~/.r90/sleep-log.json
[li] optional host reminder delivery.
[p] Recommended tool contract:
[code] r90.windows(wakeTime, wakeDate, windDownMinutes=30, cycleOptions=[4,5,6], timezone)

r90.checkin(reply, date=yesterday, store="~/.r90/sleep-log.json", timezone)
r90.weekly(weekStart, entriesFile | entriesJson, target=35)

[h2] CLI Usage
[p] Calculate bedtime windows:
[pre] python3 skills/r90-sleep-planner/scripts/r90_calc.py windows \
  --wake-time 09:00 \
  --wake-date 2026-05-04 \
  --wind-down 30 \
  --cycles 4,5,6 \
  --timezone Asia/Shanghai
[p] Calculate wake suggestions from now:
[pre] python3 skills/r90-sleep-planner/scripts/r90_calc.py wake \
  --now \
  --cycles 4,5,6 \
  --timezone Asia/Shanghai
[p] Record a check-in:
[pre] python3 skills/r90-sleep-planner/scripts/r90_calc.py checkin \
  --reply
[span] 23:30-07:00
[pre] \
  --date 2026-05-02 \
  --store
[pre] /.r90/sleep-log.json \
  --timezone Asia/Shanghai
[p] Summarize a week:
[pre] python3 skills/r90-sleep-planner/scripts/r90_calc.py weekly \
  --week-start 2026-04-27 \
  --entries-file

[h2] Behavior Notes
[li] Wake-target shortcuts must show all default 4/5/6 cycle options.
[li] "I am going to sleep now" means the current time is the lights-out reference.
[li] Morning check-ins should ask for approximate sleep and wake times, not ask the user to calculate cycles manually.
[li] Scheduled reminder output should be plain text.
[li] Severe insomnia, suspected sleep apnea, long-term fatigue, or other health-risk contexts should be handled conservatively and directed toward professional help.
