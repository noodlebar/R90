# Codex Modes

## Explore

适用场景：

- 阅读结构和文档
- 形成方案和任务拆解
- 识别风险和边界

允许：

- 读代码和文档
- 写分析笔记、brief、调研结果

## Build

适用场景：

- 实现功能
- 修改脚本或页面
- 补测试和验证

允许：

- 修改项目内代码和文档
- 运行本地验证

默认不做：

- 正式部署
- 正式同步外部系统
- 正式写入稳定产物

## Release

适用场景：

- 用户明确要求进入正式交付或正式副作用阶段

允许：

- 形成稳定本地交付，或按明确流程执行工具类项目的正式发布

前提：

- 变更范围清楚
- 必要验证已完成
- 文档能解释这次动作的结果
